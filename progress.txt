## Key Decisions (from user interview)
- Default map view: all of Lebanon (zoomed out)
- Map theme: light + dark toggle
- Company detail: bottom card (slides up from bottom)
- Filters: all unselected on first load + onboarding prompt "Select industries to get started"
- Search: autocomplete dropdown, flies to marker on select
- Sidebar: collapsible, starts open on desktop
- Mobile filters: top dropdown bar with horizontal scrolling chips
- URL sharing: filter state in query params
- List view: map/list toggle with sortable table (sort by name, industry, city)
- Multi-industry: companies can have 1-3 industry tags
- No company size for MVP
- Language: English UI, Arabic data supported
- Hosting: Vercel
- Brand: modern/neutral (blues, grays, accent color)
- External links: open in new tab
- Analytics: Vercel Analytics (lightweight)
